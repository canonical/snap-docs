#  ofono interface

`ofono` allows operating as the oFono service, enabling privileged access to configure, observe and use oFono devices.

**Auto-connect**: no

```{note}
The `ofono` slot is unsupported for {ref}`parallel instances <interfaces-parallel-installs-unsupported>`. The slot owns a unique system-wide resource that instances would conflict over.
```
