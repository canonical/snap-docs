#  avahi-observe interface

`avahi-observe` allows discovery on a local network via the mDNS/DNS-SD protocol suite.

**Auto-connect**: no

```{note}
The `avahi-observe` slot is unsupported for {ref}`parallel instances <interfaces-parallel-installs-unsupported>`. The slot owns a unique system-wide resource that instances would conflict over.
```
