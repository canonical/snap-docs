#  location-observe interface

`location-observe` allows access to the current physical location.

**Auto-connect**: no

```{note}
The `location-observe` slot is {ref}`unsupported for parallel instances <interfaces-parallel-installs-unsupported>`. The slot owns a unique system-wide resource that instances would conflict over.
```
