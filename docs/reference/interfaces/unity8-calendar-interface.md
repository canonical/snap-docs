#  unity8-calendar interface

`unity8-calendar` enables snaps to access the Unity 8 calendar interface, and consequently, read and change events in the Unity 8 global calendar.

**Auto-connect**: no

```{note}
The `unity8-calendar` slot is {ref}`unsupported for parallel instances <interfaces-parallel-installs-unsupported>`. The slot owns a unique system-wide resource that instances would conflict over.
```
